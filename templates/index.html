Methodology & Sources

Token cost estimates are calculated from Claude Code's local JSONL session logs using published Anthropic API pricing. Each turn's input, output, cache-write, and cache-read token counts are multiplied by the per-model rates: cache reads at 0.1× the input rate, cache writes at 1.25×.

About that large token count. Claude Code uses prompt caching aggressively — on every turn, the full conversation context is re-read from cache. A single long session can accumulate hundreds of millions of cache-read tokens. These are real (cheap) API charges and are included in the token count, but the cost estimate applies the correct 10% rate so the dollar figure is not similarly inflated.

Plan vs. API comparison caveat. The "Est. API Cost" answers: what would this exact usage have cost at pay-per-token rates? Two important limits to that comparison:

  1. Subscription plans are quota-based, not token-based. Anthropic controls actual limits and billing. Usage limits for Claude Code subscribers were doubled on May 6, 2026 — see this announcement.
  2. Caching behavior on a subscription plan may differ from direct API use. The estimate assumes you would replicate the identical usage pattern on the API, which may overstate what you'd actually pay.
